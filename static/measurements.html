API измерений

Программа обеспечивает измерение уровня сигнала (RSSI), отношения сигнал/шум (SNR), определение интерференции. API доступен по адресам:

МетодURLНазначение
POST/api/measurements/{plan_id}Добавить замер
GET/api/measurements/{plan_id}Список замеров
POST/api/measurements/{plan_id}/calculate?x=&y=Расчёт RSSI в точке
POST/api/measurements/{plan_id}/previewТепловая карта RSSI
POST/api/measurements/{plan_id}/snrКарта SNR
POST/api/measurements/{plan_id}/interferenceКарта интерференции
