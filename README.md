# CoworkWiFi Planner

Веб-приложение для проектирования беспроводной сети Wi-Fi в коворкинге.

## О проекте

Курсовой проект по профессиональному модулю **ПМ.06 Сопровождение информационных систем**,
специальность **09.02.07 Информационные системы и программирование**.

**Тема:** План внедрения беспроводной сети офиса и программа проверки зоны покрытия в коворкинге.

**Автор:** Скрыпкин М. Ю.  
**Группа:** СИП-323/24  
**Учебный год:** 2026–2027

## Возможности

- 🗺 **Редактор плана** — рисование стен, дверей, окон, комнат с нуля
- 🪑 **Мебель и устройства** — диваны, столы, ПК, принтеры, камеры, IoT-датчики
- 📡 **Точки доступа** — из каталога реальных моделей (Cisco, Ubiquiti, TP-Link и др.)
- 🌊 **Тепловые карты** — RSSI, SNR, интерференция с учётом стен
- 🎯 **Оптимизация размещения** — автоподбор количества и координат AP
- 📊 **Расчёт нагрузки** — сколько клиентов обслуживает каждая точка
- 📻 **SSID-профили** — корпоративный, гостевой, IoT
- 🎛 **Контроллер WLC** — балансировка, роуминг, NMS
- 🔌 **Анализ СКС** — расчёт длин кабельных линий
- 📄 **Экспорт отчётов** — PDF, CSV, XLSX

## Стек

- **Backend:** Python 3.11+, FastAPI, SQLAlchemy, SQLite
- **Frontend:** HTML5, CSS3, Vanilla JavaScript, SVG, Canvas
- **Аутентификация:** JWT + PBKDF2-SHA256
